# AcquiredUtils Privacy

AcquiredUtils is a client-side Minecraft Fabric mod.

## Data Collection

AcquiredUtils does not intentionally collect, sell, or transmit personal information to an AcquiredUtils-owned external server or database.

The mod does not include telemetry, analytics, advertising, or an external account-tracking system.

## Network Communication

AcquiredUtils does not add a separate web service or external data-collection endpoint for player information.

The mod may interact with the Minecraft server the player is already connected to when a feature requires information that is available through normal Minecraft/Fabric client-side mechanisms. This does not mean that AcquiredUtils sends player information to an AcquiredUtils-owned server.

## Local Data

AcquiredUtils may store configuration and locally managed feature data on the player's computer. This can include settings, feature state, and achievement-related client data.

Any future feature that changes how player information is handled should be documented here before it is introduced.

## Changes

This privacy policy may be updated when the mod's functionality changes. The latest version included with the mod is the applicable version for that release.
