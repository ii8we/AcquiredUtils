## Compatibility

AcquiredUtils is developed without mixins to avoid conflicts with other mods that modify the same Minecraft classes. It relies on Fabric API events and supported APIs whenever possible to provide better compatibility with other mods.

## Installation

1. Install Minecraft 1.21.11 with Fabric Loader.
2. Install the required Fabric dependencies.
3. Download the AcquiredUtils release `.jar`.
4. Place the `.jar` in your Minecraft `mods` directory.
5. Launch Minecraft using your Fabric installation.
